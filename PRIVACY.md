# Privacy Policy

Shorts-autopilot is a personal tool run locally by its owner to create and upload videos to the owner's own YouTube channel.

## Data accessed
Shorts-autopilot uses the YouTube Data API to read public trending video information and to upload videos to the channel the owner authorizes.

## Data storage
OAuth tokens and settings are stored only on the owner's local computer. No data is sent to any server other than Google, YouTube, and the AI services configured by the owner.

## Data sharing
Shorts-autopilot does not sell, share, or transfer user data to third parties.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions
